How to play

Quick guide to participate in Katapult's World Cup 2026 Office Pool

1

🔐 Log in with your corporate email

Open the pool link and enter your name and @katapultlabs.ai email. You're registered automatically. The admin enters an extra secret code for full control.

2

📷 Set your profile photo

Go to 👥 Players. On your card you'll see a camera icon — tap it to upload your photo. It compresses automatically and appears on the leaderboard.

3

🎲 Wait for the team draw

The admin runs the draw from 👥 Players. Each participant gets a random team. If that team wins, you get +10 bonus pts!

4

⚽ Make your predictions before each match

Go to ⚽ Predictions. Enter the score you predict for each match. It saves automatically as you type.

🔒 Auto-lock: Fields lock 10 minutes before kickoff. You'll see a ⏰ warning when less than 1 hour remains.

🚀 How to publish online
So the whole team can access from their own devices with synced data.

🏆 Firebase + Netlify/Vercel FREE

Result: A unique link for everyone, predictions and leaderboard synced in real time.

  1. Go to console.firebase.google.com → Create project
  2. Enable Realtime Database → Test mode
  3. In ⚙️ Settings → Add Web app → Copy the 3 credentials
  4. Open this file → Firebase Config → paste credentials
  5. Upload to Netlify Drop or push to GitHub → Vercel
  6. Done! Share the link via Slack
💡 Admin code is katapult2026. Change it in the ADMIN_SECRET variable.

⚡ GitHub + Vercel (auto-deploy) FREE

  1. Create a GitHub account at github.com
  2. Create a new repository and upload this HTML file as index.html
  3. Go to vercel.com → New Project → Import your GitHub repo
  4. Every time you update the file in GitHub, Vercel republishes in ~10 seconds
⚡ Best option for non-developers — no terminal needed, just drag & drop files to GitHub.
