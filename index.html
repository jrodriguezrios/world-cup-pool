How to play

Quick guide to participate in Katapult's World Cup 2026 Office Pool

1

🔐 Log in with your corporate email

Open the pool link and enter your name and @katapultlabs.ai email. You're registered automatically. The admin enters an extra secret code for full control.

2

📷 Set your profile photo

Go to 👥 Players. On your card you'll see a camera icon 📷 — tap it to upload your photo. It compresses automatically and shows on the leaderboard.

3

🎲 Wait for the team draw

The admin runs the draw from 👥 Players. Each participant gets a random team. If that team wins the tournament, you get +10 bonus pts!

4

⚽ Make your predictions before each match

Go to ⚽ Predictions. Enter the score you predict for each match. It saves automatically as you type.

🔒 Auto-lock: Fields lock 10 minutes before kickoff. You'll see a ⏰ warning when less than 1 hour remains. Don't miss your prediction!

🚀 How to publish the pool online
So the whole team can access from their own devices with synced data.

🏆 Firebase + Netlify FREE

Result: A unique link for everyone, predictions and leaderboard synced in real time.

  1. Go to console.firebase.google.com → Create project → "Katapult-Polla-2026"
  2. Enable Realtime Database → Test mode
  3. In ⚙️ Settings → Add Web app → Copy the 3 credentials
  4. Open this file → Firebase Config → paste credentials
  5. Download and drag to app.netlify.com/drop
  6. Done! Share the link via Slack
💡 Admin code is katapult2026. Change it in the ADMIN_SECRET variable at the top of the script.

⚡ Quick mode: Netlify only FREE

  1. Download this HTML file
  2. Go to app.netlify.com/drop → drag the file
  3. Share the link via Slack
⚠️ In local mode each user saves data only in their browser. No sync between devices.
